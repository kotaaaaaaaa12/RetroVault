3DS comparison test

Start with Baseline, then test one other condition using the same game. Tap Start Game inside the player. Finish each test before starting another. Results remain on this device after a reload.

Memory figures measure the core's WebAssembly region, not actual total RAM or GPU use. An interrupted result does not identify why the page closed. This test does not confirm a crash fix.

Tests start with fresh temporary game saves and native settings. They do not load or write your normal game saves. ROM downloads can reuse the device cache. Baseline uses 1x internal resolution; each other condition changes one setting only.

Shader cache OFF changes citra_use_hw_shader_cache only. Hardware shaders OFF changes citra_use_hw_shaders only and may be slower. Both comparisons use the same clean baseline, not the preceding test's settings.
